Key Property
Interoperability is geometric.
A Windows file at (3,1,5) and a Linux file at (4,1,5) are neighbours — distance 1 on X axis. The cube knows they are related. No protocol negotiation. No network share. No mounting. Proximity in Z7³ space IS the relationship.
